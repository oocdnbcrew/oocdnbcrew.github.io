# Out of Control – App-Hülle

Kleine Rahmen-Seiten um die Google-Apps-Script-Web-Apps von Out of Control,
damit der Google-Hinweisbalken nicht erscheint. Inhalt und Daten kommen weiterhin von Google.

- `l/` OoC Links / Zentrale / Volunteers / Artists
- `k/` Getränke-Kasse
- `f/` Fotomanagement

Alle Adress-Parameter werden an die App durchgereicht (`l/?hub=1` = Zentrale).
